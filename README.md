# EDA_Assignment
# Breast Cancer EDA and MLP Classification

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) and Machine Learning to analyze a breast cancer dataset and classify tumors as benign or malignant. Data analysis and visualization are used to understand the dataset, and a Multi-Layer Perceptron (MLP) classifier is used for prediction.

## Objectives
- Explore and understand the breast cancer dataset.
- Perform data analysis and visualization.
- Prepare the data for machine learning.
- Build an MLP classification model.
- Evaluate the model's performance using suitable evaluation metrics.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load the dataset.
2. Inspect and understand the data.
3. Perform exploratory data analysis and visualization.
4. Preprocess the data for model training.
5. Train the Multi-Layer Perceptron (MLP) classifier.
6. Evaluate the model and analyze the results.

## Dataset
The dataset contains breast cancer-related features used to classify tumors as benign or malignant. Include the dataset file in this repository or provide the original dataset source link, depending on the assignment requirements.
