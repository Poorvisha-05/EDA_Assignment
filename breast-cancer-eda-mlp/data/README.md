# Dataset

**Breast Cancer Wisconsin (Diagnostic) – WDBC**

- UCI Repository: https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
- Kaggle copy: https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data
- Also bundled in scikit-learn: `sklearn.datasets.load_breast_cancer()`

569 patients · 30 numeric features · target `diagnosis` (0 = Malignant, 1 = Benign)

`breast_cancer_wisconsin.csv` is created by `src/eda_visualization.py`.
`processed/` holds the standardised train / validation / test CSVs.
